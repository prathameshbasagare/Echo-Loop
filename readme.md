# Echo Loop

**Echo Loop** is a mind-bending time-loop puzzle game where you must cooperate with your past selves to escape.

![Echo Loop Banner](https://via.placeholder.com/800x400?text=Echo+Loop+Game)

## 🎮 About the Game

Trapped in a repeating cycle, you must navigate through increasingly complex chambers. But you are not alone—every time the loop resets, a "ghost" of your previous attempt replays your actions exactly.

Use this to your advantage! Coordinate with your past selves to hold down multiple buttons simultaneously, pass items (conceptually), and unlock doors that would be impossible to open alone. But be careful: touching your past self causes a temporal paradox, collapsing the timeline!

## ✨ Features

*   **Time Loop Mechanic**: Your past actions replay as ghosts in subsequent loops.
*   **Cooperative Puzzles**: Solve puzzles that require multiple "players" by layering your own timeline.
*   **15 Challenging Levels**: From simple button-door puzzles to complex mazes and timing gauntlets.
*   **Paradox System**: Avoid contact with your ghosts to maintain timeline integrity.
*   **Variable Spawn Points**: Later levels spawn you in different locations each loop, requiring strategic planning.
*   **Progression System**: Unlock levels as you complete them; progress is saved automatically.

## 🕹️ Controls

| Key | Action |
| :--- | :--- |
| **W / Up Arrow** | Move Up |
| **A / Left Arrow** | Move Left |
| **S / Down Arrow** | Move Down |
| **D / Right Arrow** | Move Right |
| **P / Esc** | Pause Game |
| **F (Hold)** | Fast Forward (2x Speed) |

## 🚀 Getting Started

### Prerequisites
*   Node.js (v14 or higher)
*   npm

### Installation

1.  Clone the repository:
    ```bash
    git clone https://github.com/prathameshbasagare/echo-loop.git
    cd echo-loop
    ```

2.  Install dependencies:
    ```bash
    npm install
    ```

3.  Start the development server:
    ```bash
    npm run dev
    ```

4.  Open your browser and navigate to the local URL provided (usually `http://localhost:5173`).
